# Week 4 – CMOS Circuit Design (sky130-style)

## 📘 Overview

This project is part of the **VSD–IAT Week 4 Task**, focusing on **CMOS circuit design and SPICE simulation** using the **SkyWater SKY130 PDK**.  
It connects **transistor-level characteristics** to **Static Timing Analysis (STA)** concepts — showing how device physics, sizing, and variations impact circuit delay, switching threshold, and noise margins.

---

## 🧠 Objectives

1. Study **MOSFET I–V characteristics** (Id–Vds, Id–Vgs)
2. Extract **Threshold Voltage (Vt)**
3. Design and simulate a **CMOS inverter**
4. Obtain **Voltage Transfer Characteristic (VTC)**
5. Perform **transient analysis** to measure propagation delays
6. Calculate **noise margins**
7. Analyze **power supply and device variation** effects
